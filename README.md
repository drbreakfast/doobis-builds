# Doobis builds

Playtest builds of **Doobis**, a 2D pixel-art co-op action RPG in development.
Every new build is published here automatically.

**Download the newest build:**
https://github.com/drbreakfast/doobis-builds/releases/latest/download/Doobis.zip

Unzip it anywhere and run `Doobis.exe` (Windows). If Windows warns about an unknown app,
click "More info" → "Run anyway". `version.txt` inside says which build you have.
Co-op uses Steam (Spacewar test app): keep Steam running.
